# Overview

This repo is the custom work done for Ravenspace and acts as a template for the styling and customizations specific to their books. An example of a published book using these customizations can be found below:
URL: http://publications.ravenspacepublishing.org/as-i-remember-it/index

The book is built on the Scalar platform. This project lives inside a Scalar hook that allows it to make certain customizations to the Scalar core. This repo does not contain the Scalar platform, it is just the customizations inside the Scalar hook.

Scalar documentation: https://scalar.usc.edu/works/guide2/index

Hooks documentation: https://scalar.usc.edu/works/guide2/hooks?path=advanced-topics

# Setup

Install Scalar (see here for instructions: https://github.com/anvc/scalar/blob/master/INSTALL.txt)
Git clone this repository into a Scalar hooks folder (system/application/hooks/[HOOK FOLDER])

Install tensor and transfer plugins (if needed), to do this simply download the code from the repo and copy the contents into the [system][application][plugins] folder.
Tensor -> https://github.com/anvc/tensor
Tensor Profiles (simply place the parsers within the tensor folder) -> https://github.com/craigdietrich/tensor-profiles
Transfer -> https://github.com/Michael628/scalar-book-transfer-tool

In the hooks folder run:

- npm install - to install dependencies
- npm dev - to watch and build during development
- npm build - build for production

# Structure

Overall, the project is broken up into a series of SASS modules that control styling for different areas of the site. Future customization can be achieved by keeping the modules that you wish to keep the styling for and disabling the modules that you do not wish to keep the styling for, or want to replace with new styling modules.

The majority of this template is written as SASS code, and compiled by webpack into CSS. There are a number of other files included in the project, important files are outlined below.

## SASS

The SASS code is broken up in to modules. The goal of this structure is to allow parts of the code to be re-used for future books by choosing which modules to keep and which ones to rewrite.

The project src folder contains SASS and images that are compiled by webpack into the dist folder, which is what is displayed on the live site.

SASS modules:

- common
  - global
  - typography
- components - buttons - citations - footer - gallery - header - menu - mobile-menu
  - tklabels - visual-path - widget
- layouts - page-headers - pages
  utility - functions - variables

## Other Important Files

ravenspace-template.js

- Javascript customizations that will be customized specific to each book

custom.php

- Controls how the files generated by this project are "injected" into the live site.
- The html content for the popup that displays when you visit the site. -->

Webpack.config.js

- Simple webpack configuration for generating the project's assets.
